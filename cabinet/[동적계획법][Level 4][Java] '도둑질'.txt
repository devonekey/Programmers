/**
 * <h1>도둑질</h1>
 * <h5>분류: 동적계획법</h5>
 * <h5>난이도: Level 4</h5>
 * <h5>풀이</h5>
 * <ul>
 * <li>순환되는 배열에서 인접하지 않은 숫자를 고르는 방법으로 최댓값을 구하는 문제이다.</li>
 * <li>배열의 마지막 위치는 시작 위치와 인접하므로 이에 주의해야 한다.</li>
 * <li>아래와 같은 방법으로 해결했다.</li>
 * <ol>
 *     <li>시작 위치의 값을 선택한다.</li>
 *     <li>특정 위치의 최댓값은 "특정 위치 - 2 위치의 최댓값"과 "특정 위치 - 3 위치의 최댓값" 중
 *     큰 값을 특정 위치의 값과 더한 값으로 계산한다.</li>
 *     <li>시작 위치를 포함했으므로 마지막 위치 - 1 위치까지 진행한다.</li>
 *     <li>"마지막 위치 - 1 위치의 최댓값"과 "마지막 위치 - 2 위치의 최댓값" 중에 큰 값을 취한다.</li>
 *     <li>이번에는 시작 위치의 값을 선택하지 않는다.</li>
 *     <li>특정 위치의 최댓값은 "특정 위치 - 2 위치의 최댓값"과 "특정 위치 - 3 위치의 최댓값" 중
 *     큰 값을 특정 위치의 값과 더한 값으로 계산한다.</li>
 *     <li>시작 위치를 포함하지 않았으므로 마지막 위치까지 진행한다.</li>
 *     <li>"마지막 위치의 최댓값"과 앞서 계산한 최댓값을 비교하여 큰 값을 취한다.</li>
 * </ol>
 * </ul>
 */
public class Solution {
    public static void main(String[] args) {
        System.out.println(solution(new int[]{1, 2, 3, 1}));
    }

    public static int solution(int[] money) {
        int answer = 0;
        int[] array = new int[money.length];
        array[0] = money[0];
        array[1] = money[1];
        array[2] = money[0] + money[2];

        for (int i = 3; i < money.length - 1; i++) {
            array[i] = money[i] + Math.max(array[i - 2], array[i - 3]);
        }

        answer = Math.max(array[money.length - 2], array[money.length - 3]);
        array = new int[money.length];
        array[0] = 0;
        array[1] = money[1];
        array[2] = money[2];

        for (int i = 3; i < money.length; i++) {
            array[i] = money[i] + Math.max(array[i - 2], array[i - 3]);
        }

        answer = Math.max(answer, array[money.length - 1]);

        return answer;
    }
}
